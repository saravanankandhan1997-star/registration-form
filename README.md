# JS DOM Projects - Form Validation & Character Counter
 
This repo includes two small JavaScript projects created for practicing DOM manipulation and real-time validation. No frameworks used, only pure HTML, CSS, and JS.
 
---
 
### 🔹 Project 01: Live Registration Form Validation
A responsive registration form with instant validation feedback.
 
**What it does:**
- Name cannot be left empty - shows error if empty
- Email checks for correct format using Regex
- Password validates for minimum 6 characters
- Submit button is disabled by default and only enables when all inputs are valid
 
**What I Learned:**
- Form validation, `preventDefault()`, Regular Expressions, `disabled` property handling
 
### 🔹 Project 02: Live Character Counter for Textarea
A simple textarea with a live character counting feature.
 
**What it does:**
- Shows maximum limit (200 characters)
- Updates counter on every `input` event (e.g., 45/200)
- Calculates and displays remaining characters
- Shows a warning message and stops typing when limit is exceeded
 
**What I Learned:**
- `input` event listener, `maxlength` attribute, dynamic textContent update
